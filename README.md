# 🍔 Stellar Burgers Test Automation

Автоматизированное тестирование веб-приложения [Stellar Burgers](https://stellarburgers.nomoreparties.site/) с использованием **Selenium**, **Pytest** и **Allure**.

---

## 🧪 Технологии

- Python 3.13+
- Selenium WebDriver
- Pytest
- Allure Report
- Page Object Model (POM)
